# Information about this repository.

This is a repository of leetcode solutions performed as a means of getting back into C++ after spending time away from it, relearning seldom used algorithms, potentially learning new algorithms and hopefully for the education of others.

It is starting off as a 5 week project to complete 70 targetted questions to learn the most fundamental algorithms necessary and will probably continue to be updated on a smaller scale after this period. Please see my other blog repository if you wish to read about this journey.

You will find that the structure will be that the question, the solution and a writeup of my thought process with be all within a single folder. This is done to show understanding and the programming process used overall.

I hope you enjoy looking at some of the algorithms I have been working on and find it helpful.


## Additional note.

You may occasionally find a scratchpad document in this folder with either easier answers that don't warrant an answer done as a warmup or review questions which were quickly done to revisit a concept, this may regularly be modified tidied or deleted.
