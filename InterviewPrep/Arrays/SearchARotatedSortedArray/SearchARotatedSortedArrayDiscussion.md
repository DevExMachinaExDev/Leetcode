## search
So working off the above principle (the one array being sorted, not the me being dumb part) we can assume that the split is in one half of the array and we know that is the side where the middle is higher or lower to the left or right pointer. So really once you have your sorted size you can simply check if the value is in that sorted part by checking if it is between the middle value and the end value if it is we zoom in on that sorted array if its not in there it must be on the unsorted side therefore we zoom in. We do this until we find our value or run out of moves. Since its a relatively standard binary search we get O(logn) time complexity with O(1) space complexity due to only a few small variables being needed.
